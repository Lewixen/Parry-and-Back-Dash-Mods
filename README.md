# Parry Mod

A Sekiro-inspired parry for Hollow Knight. Deflect enemy and boss attacks with a dedicated key, with hand-drawn animations, custom sounds and bosses that react to your parries.

Not every attack can be parried. Finding out which ones is part of the fun.

## Features

- **A dedicated parry key** with a short timing window. You can rebind it in the Mods menu, for keyboard and controller.
- **Hand-drawn parry animations** on the ground, in the air and on walls, plus a heavy parry with its own animation and sound for the strongest attacks.
- **Knockback that depends on the attack.** Light hits push you back a little, heavy ones much further.
- **Parrying in the air** bounces you up like a pogo.
- **Bosses react.** Some attacks get cancelled, some bosses stagger or retreat, and some projectiles fly back at whoever threw them.
- **Stunnable bosses** build up stun from parries.
- **Shinobi's Charm**, a new charm that warns you about attacks you can't parry and makes parrying easier. It costs 3 notches and can be found near the entrance of Howling Cliffs.

## Installation

The easiest way is [Lumafly](https://themulhima.github.io/Lumafly/): search for **ParryMod** and install it. Lumafly installs SFCore, which the mod needs, by itself.

To install by hand:
1. Install the Hollow Knight Modding API.
2. Install **SFCore**.
3. Download `ParryMod.zip` from [Releases](../../releases) and extract it into `Hollow Knight/hollow_knight_Data/Managed/Mods/ParryMod`.

## Optional: Back Dash

A separate mod that brings back the cut back dash from the game's beta. You can use it with or without Parry Mod. See [Back Dash](BACKDASH.md).

## Notes

- If you use a Custom Knight skin, the parry animations show the original Knight, because they are new hand-drawn frames that skins don't include.
- The ideas, drawings and sound edits are mine. The code was written with the help of Claude (AI).
